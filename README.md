# Custom-8-Bit-RISC-CPU
For my final project for the Titan Summer Research Program involving AI-Driven Chip Design I chose to construct an 8-bit Custom ARM/RISC-V adjacent CPU. Given the resources at hand, namely the free version of ChatGPT, I attempted to construct it as close to what is commercially available as far as CPUs are concerned. The assignments in class provided much of the necessary building blocks; such as decoders, multiplexers, adders, flip-flops, and registers to aid in the process of development. 

I chose to build an 8-bit Custom ARM/RISC-V adjacent CPU to challenge and familiarize myself with the architecture of both design philosophies. I must admit that I did not initially choose to mix the ARM and RISC-V architectures, only doing so for sake of time and convenience. The ALU includes a custom ISA that uses variables or assignments similar to assembly instructions (e.g. ADD, SUB, AND, NOT). 

There are quite a couple design decisions that I took some liberty with that differentiate this CPU from typical RISC-V processors. Namely the 8-bit datapath, 8 registers, inclusion of a NOT operation. The deviation would be the status flags which are inspired by the ARM Architecture.
